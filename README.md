# 🛍️ Myntra Clone

A frontend **Myntra Clone** built using **HTML and CSS**. This project recreates the basic layout and visual structure of the Myntra fashion e-commerce website, including navigation, search, promotional banners, product categories, and footer sections.

## 📌 Project Overview

This project is created for learning and practicing **frontend web development**, especially HTML structure, CSS styling, responsive layouts, navigation components, and organizing static website assets.

The homepage includes:

* Myntra-style navigation bar
* Men, Women, Kids, Home & Living, Beauty and GenZ categories
* Search bar
* Profile, Wishlist and Bag sections
* Promotional banner
* "Medа Worthy Brands to Bag" section
* "Shop by Category" section
* Footer with shopping categories
* Copyright section

## The main HTML structure contains the header, navigation, main content sections, and footer.

## 🚀 How to Run the Project

### 1. Clone the repository

```bash
git clone https://github.com/jaiminpan188/Myntra-Clone.git
```

### 2. Open the project

```bash
cd Myntra-Clone
```

### 3. Open in VS Code

```bash
code .
```

### 4. Run the website

You can simply open:

```text
index.html
```

in your browser.

Alternatively, if you have the **Live Server** extension installed in VS Code:

1. Open `index.html`
2. Right-click inside the file
3. Select **Open with Live Server**
